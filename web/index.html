A NOTE ON PRIVACY

Your work stays yours.

Your resume is read in your browser and converted to text for tailoring. That text, along with your selected company and any job details, is sent to the Gemini API using the API key configured on your local server. CareerLens does not save your file or request. Check Google's current API data policies before sending sensitive information.

Generated edits can be inaccurate. Review your resume carefully and correct anything that doesn't reflect your actual experience.
